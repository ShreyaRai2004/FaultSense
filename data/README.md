# Data

This project uses the **AI4I 2020 Predictive Maintenance Dataset** from the UCI Machine Learning Repository (Dataset 601).

The dataset is not bundled in this repository. Run:

```bash
python download_data.py
```

The script downloads the dataset through `ucimlrepo` and saves it as `data/ai4i2020.csv`.

Source: https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset
DOI: https://doi.org/10.24432/C5HS5C
